# 对话理解专项基准规划（ai-bench-chat.cjs，600 遍）

> 2026-09-12 规划稿。目标：测试 AI 在表情/网络用语/视频文案+评论/跨消息污染/带偏与关键信息/回复质量六个维度的表现。

## 维度与判据（纯规则评分：关键词类命中 or 禁止词缺席）

1. **表情识别与回话（8 例）**：emoji 承载核心意图，回复必须命中意图语义类。
   🎉中奖→恭喜/牛/真的假；😭输了→抱抱/心疼/下一；🍲邀约→去/吃/哪家；💪健身→练/厉害/累；
   🎂生日→快乐/蛋糕/哪天；😔面试挂→下次/抱抱/咋；🙉不敢看→敢/结果/哈哈；🔥火了→火/恭喜/多少。
2. **网络用语理解（10 例）**：尊嘟假嘟/绝绝子/栓Q/emo/上头/666/破防/yyds/画大饼/吃瓜。
   通过 = 命中语义类 **或** 自然询问含义（什么意思/啥意思——追问也算懂）。
3. **视频=文案+评论（6 例）**：只给 videoPageTitle/Description/videoComments，无画面帧（主路径）。
   蛋炒饭教学/地铁让座摆拍/猫开冰箱/深蹲翻车/苍蝇馆子/川西旅行。
   通过 = 回复命中内容关键词；同时统计"编造检测"（回复含画面臆造词则记污染）。
4. **跨消息污染（10 例）**：
   - 同联系人记忆回指：爬山话题×2 → 游戏话题×2 → "我之前说想去干啥来着？" → 必须命中"爬山"；
   - 双联系人隔离：小明（爬山/蛋炒饭）与 小红（学吉他）交错 6 轮 → 小红回复禁含"爬山/炒饭"，小明回复禁含"吉他/琴"。
5. **带偏与关键信息（7 例）**：
   - 带偏恢复：游戏话题×2 → "人活着到底为了什么" → "算了不聊这个，我卡在第三关了" → 拉回轮必须命中游戏/关卡；
   - 多信息长句 4 例（生日+手机摔碎 / 上岸+普通学校 / 爸不让养猫+😢 / 三个月没发工资）→ 命中 ≥1 关键要素。
6. **回复质量守恒（每轮）**：长度 ≤42、无 Markdown、无 AI 腔、≤2 问号、不与上一条回复重复；
   每循环 1 次我方回声静默抽查。

## 运行设计

- 45 条用例/循环 × 13 循环 ≈ 600 轮；重复测量同一输入的回答方差（稳定性）。
- 联系人消息历史跨轮保留（同真实系统的 learning.messages），污染检测依赖它。
- 逐轮 JSONL（回复原文保留）+ 最终 md 报告：分维度/分用例通过率 + 失败样本 + 耗时分布。
- 节奏控制：轮间 ≥8s；冷却类失败等待 45-60s（AMD 免费网关限流自愈）。
- 预计时长 2.5-3.3 小时（AMD 单 key 15s 节流硬下限）。
