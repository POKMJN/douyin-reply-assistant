# 抖音回复助手

抖音回复助手是一款本地运行的抖音私信辅助控制台，面向需要在电脑端统一处理抖音私信、维护聊天节奏并定时补发消息的个人用户。应用基于 Electron 构建，联系人数据、运行记录与 API Key 均保存在本机，无需上传任何云端服务器。

## 功能特性

- **抖音登录与联系人同步**：内置抖音登录窗口，扫码登录后自动读取联系人列表与最近消息预览，无需手动导出数据。
- **AI 自动回复**：对方发来新消息后，按"一问一答"策略结合联系人画像生成并发送回复；支持按联系人单独开关，也可全局启停。
- **手动拟回复**：输入或粘贴对方消息，实时查看学习、生成、发送状态，确认后再发送，避免误发。
- **联系人画像**：为每位联系人独立配置称呼、关系、语气偏向、回复禁区与注意事项，让 AI 回复更贴合对话对象。
- **续火花任务**：支持文字、表情包、文字 + 表情包三种续火花方式，可立即发送或按设定时间定时补发，不受联系人 AI 开关影响。
- **回复策略**：支持关键词固定话术，命中后优先使用固定回复，未命中时再调用 AI，兼顾确定性与灵活性。
- **模型设置**：支持 OpenAI 兼容接口，可配置多个模型、一键测试连接、手动选择默认模型，并支持多模型故障转移。
- **运行记录**：完整记录 AI 调用、消息发送与失败原因，便于排查与复盘。
- **外观与行为**：主题、字体、强调色、默认 AI 语气、桌面通知与开机启动等行为统一在设置页管理，适配 Windows 11 明暗主题。

## 安装与使用

最新安装包请在 GitHub Releases 页面下载，下载后双击安装即可。

首次使用流程：

1. 启动抖音回复助手，点击右上角"登录抖音"并扫码登录。
2. 进入"模型设置"，添加一个 OpenAI 兼容接口并测试连接。
3. 返回"联系人"页，点击"检查登录并同步联系人"。
4. 为需要自动回复的联系人开启 AI 开关，或在"回复策略"中配置关键词固定话术。

> 提示：首次使用建议只对一位熟悉的联系人开启 AI 自动回复进行验证，确认效果后再逐步放开。

## 本地开发与测试

源码位于 `app-source/`：

```text
app-source/dist/       前端页面与样式
app-source/electron/   主进程、抖音自动化、AI 服务与本地存储
app-source/test/       Node 单元测试
```

运行测试：

```bash
cd app-source
npm test
```

重新打包应用 ASAR：

```bash
cd app-source
npm run package:asar
```

重新生成安装包需要 Inno Setup 6：

```powershell
& "C:\Users\22816\AppData\Local\Programs\Inno Setup 6\ISCC.exe" "setup.iss"
```

## 隐私与安全

- 应用完全在本机运行，配置、联系人画像与运行记录默认保存在 Electron 的用户数据目录，不向任何服务器上传。
- API Key 通过 Electron `safeStorage` 加密保存，仅在调用模型接口时使用。
- AI 回复仅会携带必要的信息（联系人画像、当前输入与上下文）发送到你配置的模型接口。
- 抖音登录态仅保存在本机；请勿将二维码、Cookie、密码或验证码提供给任何人。
- 请在符合平台规则与对方预期的前提下使用自动回复与续火花功能。
