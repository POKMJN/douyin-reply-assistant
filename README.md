# 抖音回复助手

本地运行的抖音私信 AI 回复助手。所有数据（登录态、聊天记录、API Key）保存在本机，不上传任何云端服务器。

> **v2.0 重构版** —— 本次为整体重写，修复了旧版"自动回复说个不停""对话被一句话带偏""视频不进上下文"等核心问题。

## 下载安装

到 [Releases](https://github.com/POKMJN/douyin-reply-assistant/releases) 页面下载最新安装包，双击安装即可。

## 核心改进（v2.0）

### 对话不再"说个不停"
- **轮次状态机**：每条消息持久化标记，同一消息只回复一次，轮询多少轮都不会重复
- **跨天自动解锁**：对方每天发"早上好"这类相同内容，新的一天会正常回复（旧版会永久静默）
- **发送方未确认时绝不抢发**：宁可漏回，也不自我对话
- **20 秒最小发送间隔**：即使判断异常也不会连发

### 对话逻辑通顺
- **接话策略层**：每轮明确"一次只做一个动作"，突兀消息不会被当成切换话题的指令
- **弱模型隔离**：只支持视觉的小参数模型不参与文字回复，避免答非所问
- **连续复读守卫**：与上一条回复重复时自动换角度重写
- **多轮上下文**：视频理解结果、话题状态、长期记忆分层注入，当前消息永远优先

### 视频理解
- 抓真实解码关键帧 + 转写音频 + 读取文案与评论
- 理解结果作为后续对话的上下文背景保留（3 天内降权引用）
- 视频回复开销 ≈ 文字回复（实测中位 13-15 秒）

### 续火花今日播报
- 真实天气（按日缓存）+ 日期/节日 + 今日热点 + 轻短祝福
- 天气提醒按数据自动生成（带伞/保暖/防晒/补水/雾霾…）
- 防复读机制对播报事实自动豁免（不会把自己生成的内容误杀）
- AI 不可用时自动降级为模板播报，不断更

### 训练场（新）
- 与 AI 对话练习：AI 拟回复 → 你改成自己的语气 → 学习
- 学到的示范进入"本人说话样例"（自动回复的最高优先级模仿对象）
- AI 原文不会被当作你的语气（防止 AI 学自己）

### 性能与稳定
- 内存自动优化：聊天页超 400MB 自动刷新释放
- 渲染分层：后台事件只更新数据区域，滚动位置与输入状态不被打断
- 全部按钮事件委托，重写后不会失效

## 功能一览

| 功能 | 说明 |
|---|---|
| AI 自动回复 | 理解文字/视频/图片/表情后自然回复 |
| 联系人画像 | 关系、称呼、语气、禁区、说话样例 |
| 定时问候任务 | AI 智能生成 / 固定文案 / 表情 / 组合 |
| 双消息模式 | 按概率连发两条，像真人 |
| 草稿审核 | AI 回复先经人工确认再发送 |
| 多账号并发 | 多账号同时运行，互不影响 |
| 话题代问 | AI 把你想了解的问题包装成自然闲聊 |
| 长/中/短期记忆 | 事实提炼 + 话题状态 + 对话历史 |
| 运行记录 | 完整日志与筛选，便于排查 |

## 安全护栏

- 每日总量 + 单联系人独立限额
- 免打扰时段静默
- 检测到抖音安全验证自动暂停
- AI 输出多重质检：拒发攻击性、客服腔、思考过程泄漏、空洞内容、格式符号
- **宁可不说，也不发不合适的话**

## 开发

```
app-source/          应用源码（Electron 主进程 + 渲染层）
app-source/tests/    测试套件（89 项单元测试 + 模拟器）
app-source/tools/    构建脚本
setup.iss            Inno Setup 安装包脚本
resources/app.asar   打包后的应用包
```

运行测试：

```bash
cd app-source
node --test tests/*.test.cjs        # 单元测试
node tests/run-all.cjs              # 连续多轮回归
node tests/conversation-sim.cjs     # 对话模拟（需应用开启调试端口）
```
